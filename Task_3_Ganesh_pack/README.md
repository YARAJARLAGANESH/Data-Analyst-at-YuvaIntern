Dataset: UCI Online Retail (Chen, 2015), DOI https://doi.org/10.24432/C5BW33  
License: CC BY 4.0

## Files
- `Task_3_Real_World_Dataset_Analysis_Ganesh.docx` — structured report
- `Task_3_Real_World_Dataset_Analysis_Ganesh.ipynb` — reproducible analysis notebook

## Run
Open the notebook in Google Colab/Jupyter and run all cells. The notebook installs/imports dependencies and fetches the real dataset from UCI via `ucimlrepo`.

Install locally if needed:
`pip install ucimlrepo pandas numpy matplotlib seaborn openpyxl`

## Important
The report intentionally does not invent computed metrics. Run the notebook, inspect the actual outputs, and update the findings section with verified results before submission. The dataset is historical and revenue is not profit.

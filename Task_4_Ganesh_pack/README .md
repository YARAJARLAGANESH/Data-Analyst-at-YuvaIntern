# Task 4 – Data Science Tool Mastery Project
**Prepared by: Ganesh**

## Project
Wine classification and exploratory analytics using Python, Jupyter, Pandas, NumPy, Matplotlib, Seaborn, scikit-learn, and SQLite (`sqlite3`).

## Files
- `Task_4_Data_Science_Tool_Mastery_Ganesh.ipynb` – practical notebook
- `data/wine_dataset.csv` – dataset export
- `sql/practice_queries.sql` – SQL practice queries
- `requirements.txt` – Python packages
- `Task_4_Report_Ganesh.docx` – project report

## Run
1. Open the notebook in Jupyter.
2. Install packages with `pip install -r requirements.txt`.
3. Run all cells from top to bottom.
4. Review the outputs and add your own interpretation to the report.
5. Save the executed notebook before submitting.

SQLite is accessed using Python's built-in `sqlite3`; a separate SQL server is not required. Power BI is not required for this version.

## Dataset
Wine recognition benchmark dataset, distributed by scikit-learn and originating from the UCI Machine Learning Repository. This is a small educational benchmark dataset, not a representative commercial sales dataset.
